# Temporal and Trend Analysis of Renewable Energy Power Plants

This project presents temporal visualizations of renewable energy power plant data using Python and Streamlit.

The analysis focuses on renewable energy capacity growth, yearly installations, and country-based temporal trends across multiple European countries.

## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- Seaborn

## Visualizations

- Multi-Line Chart
- Area Chart
- Stacked Area Chart
- Bar Chart

## Dataset

https://www.kaggle.com/datasets/eugeniyosetrov/renewable-power-plants

## Run the Project

```bash
streamlit run multi_line_chart.py
```

```bash
streamlit run area_chart.py
```

```bash
streamlit run stacked_area_chart.py
```

```bash
streamlit run bar_chart.py
```
